## ۱. معرفی و اهداف سامانه

**Adaptive Trader AI** یک نرم‌افزار حرفه‌ای، ماژولار و قابل آزمون برای معاملات الگوریتمی تطبیقی است که به طور اختصاصی با هدف ادغام دانش معاملاتی کاربر، تحلیل آماری بازار و یادگیری ماشین طراحی شده است.

### 🛡️ اصول قطعی امنیت و معاملات
1. **ممنوعیت مطلق معامله روی حساب واقعی:** معامله واقعی (`LIVE_TRADING`) به صورت ساختاری و در ریشه کد مسدود است. هیچ گزینه یا کلیدی برای ارسال سفارش به حساب واقعی وجود ندارد.
2. **حالت پیش‌فرض سیستم (`SIGNAL_ONLY`):** سامانه به صورت پیش‌فرض در حالت تولید و ثبت سیگنال بدون ارسال سفارش اجرا می‌شود.
3. **گیت امنیتی پنج‌گانه برای حساب دمو:** اجرای دمو (`DEMO_TRADING`) تنها پس از احراز قطعی کد دمو بودن حساب (`trade_mode == 0`)، تأیید سرور، فعال‌سازی صریح کلید دمو و خاموش بودن کلید توقف اضطراری مجاز است.
4. **کلید توقف اضطراری پایدار (Persistent Circuit Breaker):** قابلیت توقف فوری که وضعیت آن در حافظه و پایگاه داده ذخیره شده و پس از ریستارت سرور نیز پایدار می‌ماند.
5. **تضمین عدم نشت اطلاعات آینده (Anti-Lookahead Bias):** تمام ویژگی‌ها صرفاً از داده‌های گذشته تا لحظه تصمیم‌گیری استخراج می‌شوند و برچسب‌گذاری حد سود/ضرر با روش محافظه‌کارانه برخورد همزمان پیاده‌سازی شده است.
6. **گردش‌کار تایید انسانی قوانین:** هیچ قانون استخراج‌شده از اسناد (PDF/TXT/CSV/XLSX) تا پیش از تایید صریح کاربر در داشبورد وارد استراتژی فعال نمی‌شود.

## ۲. ساختار پروژه


## ۳. راهنمای راه‌اندازی سریع در ویندوز (Quickstart Guide)

### پیش‌نیازها
- سیستم‌عامل Windows 10/11
- پایتون نسخه ۳.۱۱ یا بالاتر (در محیط با پایتون ۳.۱۴ آزمایش شده است)
- ترمینال MetaTrader 5 (نصب و با حساب دمو لاگین شده)

### ۱. ساخت فایل تنظیمات محیطی
فایل نمونه `.env.example` را به `.env` کپی کنید:
```powershell
Copy-Item .env.example .env
```

### ۲. اجرای پایگاه داده و مهاجرت‌ها
```powershell
python -m backend.app.db.init_db
alembic upgrade head
```

### ۳. اجرای سرور و داشبورد فارسی
```powershell
python -m backend.app.main
```
سپس مرورگر خود را باز کرده و به آدرس زیر مراجعه فرمایید:
👉 **`http://localhost:8000/dashboard`** یا **`http://localhost:8000/`**

مستندات تعاملی Swagger API نیز در آدرس زیر در دسترس است:
👉 **`http://localhost:8000/docs`**

## ۴. اجرای آزمون‌های خودکار (Automated Tests)

تمام بخش‌های سیستم دارای آزمون‌های خودکار هستند:

```powershell
# اجرای کامل ۵۰ آزمون
pytest backend/tests -v

# اجرای آزمون‌های امنیتی و گیت‌های ریسک
pytest backend/tests/security -v

# اجرای آزمون‌های داده و جلوگیری از نشت اطلاعات
pytest backend/tests/data_ml -v

# اجرای آزمون‌های یکپارچه‌سازی و اتصال زنده MT5
pytest backend/tests/integration -v

# اجرای آزمون‌های واحد
pytest backend/tests/unit -v
```

## ۵. صفحات اصلی داشبورد وب

1. **صفحه وضعیت سامانه (System Status):** نمایش برخط وضعیت اتصال ترمینال MT5، اثبات دمو بودن حساب، اکوئیتی، بالانس و کلید وضعیت توقف اضطراری.
2. **صفحه اسناد و استراتژی (Documents & Strategy):** بارگذاری فایل‌های PDF/TXT/CSV/Excel، استخراج قوانین با ذکر صفحه و منبع، نمایش ابهامات متنی و دکمه‌های تایید یا رد انسانی.
3. **صفحه داده و مدل هوش مصنوعی (Data & Model):** انتخاب نماد و بازه، آموزش مدل‌های سبک (Logistic Regression, Random Forest)، ارزیابی Out-of-Time و مقایسه مدل نامزد با فعال.
4. **صفحه بکتست (Backtest):** اجرای شبیه‌سازی با هزینه‌های واقعی (اسپرد، کمیسیون، لغزش)، تحلیل افت سرمایه و سناریوهای استرس.
5. **صفحه سیگنال‌ها و دمو (Signals & Demo):** ارزیابی لحظه‌ای کندل، صدور سیگنال با کلید Idempotency، بررسی فیلترهای ریسک و تاریخچه سفارش‌های دمو.
6. **صفحه تنظیمات و گزارش رخدادها (Settings & Audit):** مشاهده محدودیت‌های ریسک و لاگ‌های امنیتی ثبت‌شده در پایگاه داده.
