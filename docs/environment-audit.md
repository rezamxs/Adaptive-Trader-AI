## ۳. نتیجه بررسی اتصال ترمینال MetaTrader 5

اتصال مستقیم پایتون به ترمینال MT5 از طریق API رسمی `MetaTrader5` ارزیابی شد:

| پارامتر ترمینال | مقدار واقعی | نتیجه ارزیابی امنیتی |
| :--- | :--- | :--- |
| **نسخه پکیج MT5** | `5.0.6231` | سازگار |
| **نتیجه فراخوانی `mt5.initialize()`** | `True` | اتصال موفق به هسته ترمینال محلی |
| **مسیر فایل ترمینال** | `C:\Program Files\<YourBroker> MT5\terminal64.exe` | ترمینال کارگزاری the configured broker نصب و در دسترس است |
| **وضعیت اتصال شبکه ترمینال (`connected`)** | `True` | ترمینال متصل به سرور بروکر است |
| **مجوز معاملات الگوریتمی (`trade_allowed`)** | `False` | کلید سراسری اجرای اکسپرت/الگوریتم در ترمینال غیرفعال است (لایه محافظ سخت‌افزاری مضاعف) |

| **تست دریافت کندل تاریخی (`copy_rates`)** | ۵ کندل M1 روی EURUSD با موفقیت دریافت شد | دسترسی به داده زنده و تاریخی تایید گردید |

## ۴. نتیجه تشخیص نوع حساب و سرور معاملاتی (Account Mode Verification)

| فیلد | وضعیت | ملاحظه امنیتی |
| :--- | :--- | :--- |
| **نام سرور** | `YourBroker-MT5` | سرور رسمی کارگزاری |
| **نوع حساب (`trade_mode`)** | `0` (`ACCOUNT_TRADE_MODE_DEMO`) | **حساب به طور قطعی و سیستمی «دمو» (Demo) است.** |
| **ارز پایه حساب** | `USD` | دلار آمریکا |
| **اهرم معاملاتی (Leverage)** | `1:40` | استاندارد مدیریت ریسک |
| **موجودی (Balance) و دارایی (Equity)** | `$97,856.75` | تطابق کامل موجودی و ارزش دمو |
| **شناسه حساب (Login)** | `******83` | طبق الزامات امنیتی، شماره حساب ماسک شده و رمز استخراج/نمایش داده نمی‌شود |

**اثبات قطعی حالت دمو:**  
ثابت `mt5.ACCOUNT_TRADE_MODE_DEMO` برابر با مقدار عددی `0` است. مقدار بازگشتی `account_info().trade_mode` دقیقا `0` ثبت شد. بنابراین حساب حاضر به صورت ذاتی و ساختاری در سمت کارگزار دمو است.

## ۵. وضعیت PostgreSQL و پایگاه داده جایگزین

- بررسی پورت 5432 و سرویس‌های ویندوز نشان داد که سرویس محلی PostgreSQL در ویندوز در حال اجرا نیست.
- **راهکار معماری:**
  - لایه دسترسی به داده با استفاده از `SQLAlchemy 2.0` طراحی شده است به گونهای که به صورت پیش‌فرض با `SQLite` (با فعال‌سازی WAL mode و کلیدهای خارجی) کار می‌کند تا اجرای سیستم به صورت پرتابل، بدون نیاز به نصب سرویس‌های جانبی سنگین و بدون خطا انجام پذیرد.
  - پارامتر `DATABASE_URL` در تنظیمات سیستم تعبیه شده است؛ در صورتی که کاربر سرور PostgreSQL محلی یا ریموت فراهم کند، صرفاً با تنظیم رشته اتصال در `.env` پایگاه داده به PostgreSQL تغییر می‌یابد.

## ۶. محدودیت‌های واقعی محیط (System Limitations)

1. **نبود پردازنده گرافیکی اختصاصی (No Dedicated GPU):** مدل‌های سبک (Logistic Regression, Random Forest, Decision Tree, Gradient Boosting سبک) کاملاً متناسب با CPU سیستم هستند. از مدلهای عمیق سنگین غیرضروری در فاز نخست اجتناب می‌شود.
2. **غیرفعال بودن کلید الگوتریدینگ در ترمینال MT5:** در ترمینال the configured broker گزینه "Algo Trading" خاموش است (`trade_allowed = False`). این یک مزیت حفاظتی در فازهای اولیه تولید سیگنال است. برای فاز آزمایشی دمو، فعال‌سازی این کلید توسط کاربر در ترمینال ضروری خواهد بود.
3. **پایگاه داده محلی:** سرویس دیمون PostgreSQL اجرا نیست، لذا از پایگاه داده استاندارد محلی با قابلیت سوییچ به Postgres استفاده می‌شود.
